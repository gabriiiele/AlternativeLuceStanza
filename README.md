# Luce Stanza

Editor foto per telefono, uso personale. Web app installabile (PWA) con motore WebGL: nessuna dipendenza, nessuna build.

## Provarlo
Serve un piccolo server (i file locali non permettono l'installazione come app):

    python3 -m http.server 8000

Apri `http://<ip-del-computer>:8000` dal telefono, poi "Aggiungi a schermata Home".
Per usarlo solo dal telefono, il modo più semplice è pubblicarlo con GitHub Pages (privato o pubblico a tua scelta).

## Funzioni attuali
Esposizione, contrasto, alteluci, ombre, bianchi, neri, temperatura, tinta, vividezza, saturazione,
HSL per 8 colori, curva dei toni, nitidezza, vignettatura, grana, preset (con salvataggio dei tuoi),
annulla/ripeti, confronto prima/dopo (tieni premuto), esportazione JPEG a piena risoluzione (max 4096 px).
